# Release Desk v0.1.0

The first public release of Release Desk: a native Rust workspace for managing
projects, repositories, releases, and installable desktop apps across multiple
Git providers. This release ships the desktop application, the command-line
interface, and the terminal interface for macOS, Linux, and Windows.

## Highlights

- Native desktop application built with Rust and GPUI — no Electron or browser shell.
- Project Hub for creating projects, connecting repositories, and keeping every codebase in one workspace.
- GitHub support for public and private repositories, releases, assets, and pull requests.
- GitLab.com support, including nested groups and release assets.
- Bitbucket Cloud support with repository downloads and workspace discovery.
- Gitea support for gitea.com and self-hosted instances.
- Forgejo support for self-hosted servers.
- Codeberg support through the Forgejo-compatible API.
- Azure DevOps support for organization projects and repositories.
- AWS CodeCommit support through the configured AWS CLI profile.
- Custom Gitea/Forgejo-compatible server support through a configured HTTPS origin.
- GitHub device sign-in with browser and in-app webview fallback.
- GitLab OAuth authorization code flow with PKCE.
- Gitea and Codeberg OAuth authorization code flow with PKCE.
- Microsoft Entra delegated sign-in for Azure DevOps.
- Access-token authentication for providers without a desktop OAuth flow.
- Discovery of existing Git credentials so users can reuse accounts already on the machine.
- Credentials stored in the operating system keychain instead of project files or SQLite.
- Unified release view that refreshes metadata from every connected provider.
- Last known release listing is kept when a provider request fails.
- Release assets download into each project's own release shelf.
- Downloaded assets are checked against recorded size and version metadata before install.
- Local App Store backed by SQLite that opens without contacting the network.
- Store refresh that reuses the same workspace release model as project pages.
- Repository `release-desk-store.json` manifests for names, descriptions, categories, icons, and screenshots.
- Manifest-declared release artifacts for Azure DevOps, CodeCommit, and custom CI systems.
- macOS DMG install and update into the configured Applications directory.
- Installed macOS apps can be opened directly from the Store.
- Non-DMG package formats are downloaded to the project shelf for manual installation.
- Safe repository sync that clones or fast-forwards without destructive history rewrites.
- Dry-run sync mode for inspecting what would change before touching disk.
- Project snapshots stored as `.release-desk/data.json` for local recovery.
- Project reconcile flow to restore missing repositories or export the current state.
- Pull-request listing with state filters.
- CLI commands for projects, auth, discovery, tracking, sync, releases, pull requests, backups, and initialization.
- CLI `--json` output for machine-readable automation.
- TUI with repositories, installers, pull requests, reconcile, projects, and auth tabs.
- TUI keyboard navigation for fast terminal workflows.
- Provider downloads follow an HTTPS origin allowlist and strip credentials on cross-origin redirects.
- Responsive workspace loading that keeps the desktop UI usable while data refreshes.
- Native window and application icons for macOS, Windows, and Linux.
- Cross-platform release archives for the app, CLI, and TUI with versioned folder names.
- SHA-256 checksums published for every archive and disk image.

## Installation

- **macOS:** open the matching `.dmg`, then drag `Release Desk.app` into Applications. This build is ad-hoc signed; right-click and choose Open the first time if Gatekeeper warns.
- **Windows:** extract the `.zip` and run `Release Desk.exe`.
- **Linux:** extract the app archive, then run `repo-manager`; install the included `.desktop` entry and icon for launcher integration.
- **CLI and TUI:** extract the archive, keep the binary on your `PATH`, and run `release-desk` or `release-desk-tui`.
- **Integrity:** verify downloads with `shasum -a 256 -c SHA256SUMS.txt` or `sha256sum -c SHA256SUMS.txt`.

## Notes

- Release archives contain a single top-level folder named after the archive, so extraction stays organized.
- macOS builds target macOS 14 or newer.
- macOS bundles in this release use ad-hoc signing. Developer ID signing and notarization are not configured yet.
- Linux desktop builds target the system WebKit/GTK libraries available on the distribution; the archives are built on Ubuntu 24.04.
- This is the first tagged release. Please report provider-specific edge cases with the provider, platform, and reproduction steps.
