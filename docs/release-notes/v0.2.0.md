# Release Desk v0.2.0

Release Desk 0.2.0 focuses on two daily workflows: keeping repository sources
current and staying in control of release downloads. This release adds in-place
source refresh, cancellable in-flight downloads, and a clearer repository picker.
The desktop app, CLI, and TUI are available for macOS, Linux, and Windows.

## New features

- Refresh repository sources without removing and re-adding them.
- Refresh from the source card or directly inside the repository picker.
- Local project sources can be rescanned to pick up newly created repositories.
- Repository picker shows which repositories are already cloned on disk and
  which are ready to clone, alongside selected and discovered counts.
- Cancel a download while it is actively transferring, not only while it is
  queued.
- Downloads now report a distinct "Stopping download…" state while cancellation
  is being handled.
- Progress is reported while downloading, and the queue stays responsive during
  large asset transfers.
- Download queue dialog is rendered as a full-window overlay with viewport-aware
  sizing and scrolling for long queues.

## Bug fixes

- Refreshing a source no longer discards custom display names, avatars, or bios
  when a provider omits those fields.
- Refreshing a source no longer fails when stored credentials cannot be read;
  Release Desk falls back to an unauthenticated request.
- A refresh that finishes after the user switches projects no longer overwrites
  the newly selected project's settings.
- Repositories that are already cloned are now shown and labeled instead of
  being hidden, so the picker no longer reports that every repository is
  "already cloned and selected."
- Repositories whose destination has not been checked yet are no longer treated
  as already cloned, which previously hid new repositories from the picker.
- Opening the repository picker now fetches the current repository list instead
  of presenting cached data as a fresh result.
- Download queue backdrop and dialog now correctly occlude the underlying view
  and no longer clip on smaller windows.
- Cancelling an active download cleans up the temporary file instead of leaving
  a partial artifact behind.
- Download size and cancellation checks remain enforced in the cancellable
  download path.

## Installation

- **macOS:** open the matching `.dmg`, then drag `Release Desk.app` into Applications. This build is ad-hoc signed; right-click and choose Open the first time if Gatekeeper warns.
- **Windows:** extract the `.zip` and run `Release Desk.exe`.
- **Linux:** extract the app archive, then run `repo-manager`; install the included `.desktop` entry and icon for launcher integration.
- **CLI and TUI:** extract the archive, keep the binary on your `PATH`, and run `release-desk` or `release-desk-tui`.
- **Integrity:** verify downloads with `shasum -a 256 -c SHA256SUMS.txt` or `sha256sum -c SHA256SUMS.txt`.

## Notes

- Release archives contain a single top-level folder named after the archive, so extraction stays organized.
- macOS builds target macOS 14 or newer.
- macOS bundles in this release use ad-hoc signing. Developer ID signing and notarization are not configured yet.
- Linux desktop builds target the system WebKit/GTK libraries available on the distribution; the archives are built on Ubuntu 24.04.
- Existing projects and credentials continue to work without migration; no manual data changes are required when upgrading from 0.1.0.
- Please report provider-specific edge cases with the provider, platform, and reproduction steps.
