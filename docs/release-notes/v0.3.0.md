# Release Desk v0.3.0

Release Desk 0.3.0 overhauls repository inspection, caching, remote update probing, and UI reliability for large multi-repository workspaces and external volumes. The desktop app, CLI, and TUI are available for macOS, Linux, and Windows.

## New features

- SQLite-backed repository cache hydrates the repository workspace immediately on launch with zero startup git subprocesses.
- Pure-stat Git reference fingerprinting (loose refs, packed-refs, reftable, and worktree `.git` files) skips unnecessary status checks when repositories have not changed.
- Tiered remote update probing (`GitHubGraphQlProbe` + `GitLsRemoteProbe`) checks remote refs and latest releases cleanly before falling back to full fetches when `Auto-fetch` is disabled.
- Project-scoped job registry and scheduler with per-volume adaptive concurrency limiting (`2` workers on HDDs, scaled higher on SSDs) and throttled focus/interval revalidation.
- Unified single-call repository icon DB lookup and live monotonic streaming progress during manual update checks.
- Redacted stderr error reporting, stale lock preflight detection, and file-level `Dirty` status summaries (modified count, sample paths, and `ORIG_HEAD` note).

## Bug fixes

- Removed fixed `30s` kill timeouts on local `fast-forward` and branch-setup operations so large checkouts on slower disks never get terminated mid-checkout.
- Stopped showing `"Pull updates"` when a `.git/*.lock` file blocks Git operations; surfaced `"Remove stale lock…"` cleanly instead.
- Fixed repository list cards shrinking horizontally after virtualized scrolling.
- Replaced fixed pixel height guesses in the update queue and download queue dialogs with viewport-bounded flex layout and proportional progress bars.
- Replaced single-slot fallback toast guessing with an explicit FIFO toast queue (`Success`, `Warning`, `Error`, `Info`) and separated quiet status messages from user notifications.

## Installation

- **macOS:** open the matching `.dmg`, then drag `Release Desk.app` into Applications. This build is ad-hoc signed; right-click and choose Open the first time if Gatekeeper warns.
- **Windows:** extract the `.zip` and run `Release Desk.exe`.
- **Linux:** extract the app archive, then run `repo-manager`; install the included `.desktop` entry and icon for launcher integration.
- **CLI and TUI:** extract the archive, keep the binary on your `PATH`, and run `release-desk` or `release-desk-tui`.
- **Integrity:** verify downloads with `shasum -a 256 -c SHA256SUMS.txt` or `sha256sum -c SHA256SUMS.txt`.
