## Summary

`release-desk.html` is a single-file web dashboard transpiled in-browser via the TypeScript compiler loaded from a CDN. It acts as a companion UI to `storytold-sync.sh`. It can read the `.release-desk/data.json` snapshot generated by the shell script using the browser File System Access API (avoiding GitHub API token and rate limit issues), or query GitHub's GraphQL/REST APIs directly when given a token. It displays repository status, allows downloading DMG installers, tracks local DMG files on a "shelf" folder, and compares local clone git HEAD revisions against the remote default branch.

## Intentional Corrections & Architectural Upgrades in Release Desk

1. **Git Status Accuracy**: Legacy only checked `localSha === remoteHead` (giving only `notcloned`, `current`, `behind`, or `unknown`). Release Desk distinguishes `NotCloned`, `Current`, `Behind`, `Ahead`, `Diverged`, `Dirty`, and `Detached`.
2. **Release Selection**: Legacy selected first matching release in API created-at order. Release Desk selects by publication date (with created-at fallback).
3. **Download Architecture**: Legacy forced user to trigger browser downloads and manually re-import or drag-and-drop into the browser. Release Desk has a built-in resumable, verified downloader streaming directly into managed storage.
4. **Pull Requests**: Legacy had dead PR rendering code and never fetched PRs. Release Desk actually fetches, filters, caches, and displays PRs.
5. **Storage Boundary**: Legacy stored loose `.manifest` files and directly modified folders. Release Desk maintains a portable SQLite database, enforces strict ArtCraft read-only safety, and isolates managed library writes.
6. **Hardcoded Metadata**: Legacy hardcoded 14 ArtCraft apps in `APPS`. Release Desk dynamically models arbitrary GitHub accounts, organizations, and repositories without hardcoded name lists.
7. **Offline Capability**: Legacy lost directory handles or needed re-prompting. Release Desk operates seamlessly offline using its persistent local SQLite database and cached files.
