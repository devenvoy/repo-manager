Connect GitHub, GitLab, Bitbucket Cloud, Gitea, Forgejo, Codeberg, Azure DevOps, AWS CodeCommit, and compatible servers.

Unified releases

Refresh release listings from any provider. Failed requests keep the last known listing instead of losing data.

A local SQLite catalog of repositories that publish verified desktop installers, with install and update support.
