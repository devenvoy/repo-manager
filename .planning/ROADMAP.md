# Repository manager roadmap

This roadmap replaces the previous phase and release plan. The desktop workflow is the priority; existing phase files are historical and do not establish completion.

1. **Trustworthy source discovery:** Add a provider account or profile, fetch its complete accessible repository catalogue, preserve selections on refresh, and display loading, errors, and data freshness. Do not represent unavailable data as empty or current.
2. **Browse and choose:** Show every discovered repository with useful metadata, search and filters. Let people choose which repositories to manage without losing sight of the rest. Support multiple sources and projects.
3. **Real Git operations:** Review destinations, clone selected repositories, inspect local state, fetch remote changes, and offer a guarded fast-forward when behind. Show per-repository progress and results; preserve local work.
4. **Real releases:** Fetch actual release history and assets for tracked repositories. Show version, notes, platform and local download state. Download selected assets into the chosen project with progress and reliable update detection.
5. **Workspace experience:** Recreate the reference dashboard's information density, navigation and immediate feedback in a polished native interface, with responsive layouts, purposeful motion and reduced-motion support.
6. **Provider and reliability coverage:** Implement and test each advertised provider explicitly, authentication and pagination, offline/error states, multiple folders, and end-to-end workflows. Verify in the actual app before claiming completion.

No publishing, packaging or release is part of this roadmap unless requested. No placeholder data or simulated success may be presented as a real operation.
