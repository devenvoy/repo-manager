<task type="auto">

</files>

<action>
1. In `credentials.rs`:
   - Implement `SecretStorePort` for secure token storage.
   - On macOS: use security-framework or keyring crate for Keychain storage; fallback to encrypted local store when headless/unsupported.
2. In `scheduler.rs`:
   - Implement `SchedulerPort` trait from `release-desk-core::port::SchedulerPort`.
   - On macOS: write launchd plist in `~/Library/LaunchAgents/` and invoke `launchctl`.
   - On Linux: write systemd unit in `~/.config/systemd/user/` and invoke `systemctl --user`.
3. In `github_client.rs`:
   - Implement `GitHubGateway` trait from `release_desk_core::port::GitHubGateway`.
   - Methods: `list_repositories`, `fetch_pull_requests`, `fetch_releases`.
   - Include user-agent and optional bearer token authentication.
4. Add unit tests for credential store, scheduler manifest generation, and GitHub client response parsing.
</action>

<verify>
Run `cargo test -p release-desk-store`.
</verify>

<done>
OS credentials, scheduler, and GitHub API gateway are fully implemented and tested.
</done>
