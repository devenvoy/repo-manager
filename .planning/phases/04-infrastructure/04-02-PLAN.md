crates/release-desk-store/src/lib.rs
</files>

<action>
1. In `release-desk-git/src/adapter.rs`:
   - Implement `GitPort` trait from `release-desk-core::port::GitPort` for `GitClient`.
   - Map `CloneState` and `CloneStatus` into `release_desk_core::git::GitSyncState`.
   - Enforce clean branch fast-forward rules and clone operations.
2. In `release-desk-store/src/downloader.rs`:
   - Implement `DownloadPort` from `release_desk_application::use_case::installer::DownloadPort`.
   - Use `reqwest` (blocking or async) to stream bytes, calculate SHA-256 on the fly, and write to staging path under `ManagedLibrary`.
3. In `release-desk-store/src/archive.rs`:
   - Implement `ArchivePort` trait from `release_desk_core::port::ArchivePort`.
   - Use `tar` and `flate2` to create `.tar.gz` portable project backups.
   - Enforce safe extraction: reject absolute paths, `..` traversal, and symlink creation pointing outside destination.
4. Add unit and integration tests for Git adapter, downloader, and archive operations.
</action>

<verify>
Run `cargo test -p release-desk-git` and `cargo test -p release-desk-store`.
