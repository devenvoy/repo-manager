# Native Application Packaging & Distribution Pipeline

<task type="auto">
<name>Configure Packaging and Distribution Pipeline</name>

<files>
resources/Info.plist,
scripts/package_macos.sh,
docs/DISTRIBUTION.md
</files>

<action>
1. Create `resources/Info.plist`:
   - CFBundleIdentifier: `com.storytold.release-desk`
   - CFBundleName: `Release Desk`
   - CFBundleDisplayName: `Release Desk`
   - CFBundleVersion, CFBundleShortVersionString, NSHighResolutionCapable, LSMinimumSystemVersion.
2. Create `scripts/package_macos.sh`:
   - Builds optimized `--release` binaries (`repo-manager` and `release-desk`).
   - Assembles `target/release/bundle/Release Desk.app` directory tree (`Contents/MacOS`, `Contents/Resources`, `Contents/Info.plist`).
   - Generates drag-and-drop installer `.dmg` or `.tar.gz` archive.
   - Includes notarization / codesign hook (gated if identity omitted).
3. Create `docs/DISTRIBUTION.md`:
   - macOS packaging, codesigning, and Apple notarization steps.
   - Linux package instructions (binary tarball, systemd service, desktop entry).
   - Windows build plan (MSVC target, MSIX/WiX installer).
</action>

<verify>
Verify `resources/Info.plist`, `scripts/package_macos.sh` is executable, and `docs/DISTRIBUTION.md` exists.
</verify>

<done>
Packaging and distribution pipeline is configured and ready.
</done>
</task>
