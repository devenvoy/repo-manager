<action>
Implement discrete use cases:
1. `use_case/project.rs`:
   - `CreateProjectUseCase`: validates name and account, stores via `ProjectStore`.
   - `ListProjectsUseCase`: queries `ProjectStore`.
2. `use_case/discovery.rs`:
   - `DiscoverRepositoriesUseCase`: queries `GitHubGateway`, filters inbox vs tracked.
   - `SetTrackingPreferencesUseCase`: updates tracking switches.
3. `use_case/sync.rs`:
   - `SyncRepositoryUseCase`: inspects clone, fast-forwards clean default branch, skips diverged/ahead/dirty, emits events.
   - `SyncAllRepositoriesUseCase`: iterates tracked repositories with cancellation check.
4. `use_case/installer.rs`:
   - `CheckInstallerUpdatesUseCase`: evaluates latest published release against shelf.
   - `DownloadInstallerUseCase`: streams download through `DownloadPort`, verifies checksum, applies retention plan.
5. `use_case/pull_request.rs`:
   - `SyncPullRequestsUseCase`: refreshes and caches pull requests.
Export all use cases cleanly from `use_case/mod.rs`.
</action>
