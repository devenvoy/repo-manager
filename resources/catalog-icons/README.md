# Language and file icons

These SVG files come from [Material Icon Theme](https://github.com/material-extensions/vscode-material-icon-theme), revision `3976c4913ec7b47b55e76605f965076f4840713d`. They are bundled for offline use under the MIT license in [LICENSE](LICENSE).

`src/icon_catalog.rs` maps languages and file formats to these original SVG assets. Several related extensions intentionally share a format icon.
